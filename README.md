# Triwizard Maze Rush
A maze-based desktop adventure game developed in C++ using the Qt framework as a university programming project.

## Overview
Triwizard Maze Rush is a fantasy-themed maze game featuring player movement, obstacles, enemy behaviour, collectibles and multiplayer networking components.

## Technologies
- C++
- Qt 5 / Qt Creator
- Object-oriented programming
- Qt networking

## Key Features
- Object-oriented game architecture
- Maze navigation and collision detection
- Enemy movement and gameplay logic
- Host/client networking implementation
- Graphical menus and game interface
- High-score and leaderboard functionality

## My Contribution
I was responsible for the game's programming, including its C++ and Qt implementation. The project was completed as part of a university assignment.

## Running the Project
1. Install a compatible Qt 5 development environment with Qt Creator.
2. Open `TriwizardMazeRush.pro` in Qt Creator.
3. Configure a compatible desktop build kit.
4. Build and run the project.

The project was developed using a Qt 5.12.12 MinGW 64-bit environment. Other configurations may require adjustments.
